# 今日学んだこと
### 2026-05-20｜WebアプリUI・画像生成AI・AIアプリ開発

**何をしたか**
- ブラウザで動くWebアプリの画面を、コードだけで作る方法を学びました（**Gradio**）。
- テキストを入力するだけでAIが画像を生成する技術（**Stable Diffusion**）を体験しました。
- 2つを組み合わせて、テキストから画像を生成する**AIアプリ**を自作しました。

**学んだ用語**
| 用語 | やさしい説明 |
|---|---|
| `Gradio` | Pythonだけでブラウザ上のWebアプリUIを作れるライブラリ |
| `gr.Interface()` | Webアプリの見た目と動作をまとめて設定する命令 |
| `fn` | アプリが実行する処理（関数）を指定するパラメータ |
| `inputs` / `outputs` | アプリの入力形式と出力形式を指定（`"text"` / `"image"` など） |
| `flagging_mode="never"` | 初心者向けに不要な報告機能をOFFにする設定 |
| `app.launch()` | 作ったWebアプリをブラウザ上で起動する命令 |
| `Stable Diffusion` | テキストの指示から画像を生成するAIモデル |
| `diffusers` | Stable DiffusionをPythonで使うためのライブラリ |
| `StableDiffusionPipeline` | Stable Diffusionの画像生成処理をまとめたクラス |
| `from_pretrained()` | 学習済みのAIモデルをダウンロードして読み込む命令 |
| `.to("cuda")` | AIモデルをGPU（高速演算チップ）上で動かすための設定 |
| プロンプト | AIへの指示テキスト。英語で書くと精度が上がりやすい |
| `pipeline(prompt).images[0]` | プロンプトから画像を生成し、1枚目を取得する |
| `image.save()` | 生成した画像をファイルとして保存する |
| docstring | 関数の説明文。引数・戻り値・処理内容を `"""〜"""` の形式で書く |
| Hugging Face | 世界中のAIモデルを公開・共有しているWebサイト |

**できるようになったこと**: テキストを入力すると画像を生成して表示するAIアプリをゼロから作れる。Hugging Faceで公開されている様々なAIモデルを切り替えて使える。
