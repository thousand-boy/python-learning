# 今日学んだこと
### 2026-05-22｜音声文字起こし・生成AI連携・会議自動要約

**何をしたか**
- 動画・音声ファイルをAIが自動でテキストに変換する技術（**Whisper**）を学びました。
- Googleの生成AI「**Gemini**」をPythonから操作する方法（**API連携**）を学びました。
- 2つを組み合わせて、会議の動画を自動で要約する**AIアプリ**を作りました。

**学んだ用語**
| 用語 | やさしい説明 |
|---|---|
| `Whisper` | OpenAIが開発した音声・動画の文字起こしAI |
| `whisper.load_model()` | 文字起こしモデルを読み込む（`"medium"` は精度と速度のバランスが良いサイズ） |
| `model.transcribe()` | 動画・音声ファイルを文字起こしする命令 |
| `result["text"]` | 文字起こし結果のテキストを取り出す |
| API | アプリやサービス同士が情報をやり取りするための「窓口・受付」。レンタルビデオ店のカウンターに例えられる |
| APIキー | APIを利用するための「会員証」。第三者に知られないよう厳重に管理する |
| `getpass()` | 入力内容を画面に表示せずに受け取る関数。APIキーなど秘密の情報を安全に入力できる |
| `google-genai` | PythonからGemini APIにアクセスするためのライブラリ |
| `genai.Client()` | GeminiのAPIキーを設定してクライアントを作成する |
| `client.models.generate_content()` | 使用するGeminiモデルとプロンプトを指定してAIに質問する |
| `model="gemini-2.5-flash"` | 使用するGeminiのモデル名を指定 |
| `response.text` | Geminiから受け取った回答テキストを取り出す |
| ハルシネーション | 生成AIが事実と異なる内容を回答してしまう現象。回答内容の確認が大切 |

**できるようになったこと**: 会議の動画ファイルを読み込ませると、自動で文字起こし→Geminiで要約という流れを一括処理するAIアプリが作れる。
